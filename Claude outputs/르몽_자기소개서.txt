[1] 르몽에 합류하고 싶은 이유를 알려주세요 (372자)
르몽은 외식업 사장님의 평균 연령이 53세이고 디지털에 익숙하지 않다는 점에서 출발한 제품입니다. 이런 사용자에게는 화면이 조금만 복잡해지거나 오류가 한 번 보여도 이탈로 이어집니다. 그 차이는 상태와 예외를 화면에서 어떻게 다루는지에서 갈린다고 봅니다.

저는 누적 800만 명이 쓰는 대출 플랫폼에서 입력과 진행 상태가 얽힌 신청 화면을 단계별 플로우로 나누고 상태 책임을 분리해 이탈률을 80% 낮췄습니다. 전역 예외 처리와 요청 제어로 운영 오류 접수도 90% 줄였습니다.

댓글몽은 플랫폼마다 다른 리뷰 데이터를 한 화면에 모으는 제품이라 상태와 예외가 뒤엉키기 쉽습니다. 기능이 늘어도 사장님이 보는 화면은 단순하게 유지되도록 만드는 일을 맡고 싶습니다.

[2] 채용 조건에 얼마나 적합한지 알려주세요 (397자)
3년 2개월간 800만 명이 사용하는 금융 플랫폼에서 React와 TypeScript로 웹을, React Native로 앱을 개발했고 운영자용 어드민도 맡았습니다.

새 기능은 요구사항을 정책과 플로우, 화면, API 단위로 정리하는 일부터 시작했습니다. SI 프로젝트에서는 기획·디자인·백엔드와 범위를 조율해 출시까지 진행했고, 공통 컴포넌트는 라이브러리 없이 직접 만들어 Figma 토큰과 Storybook으로 디자이너와 기준을 맞췄습니다.

성능은 느린 원인을 렌더링 전략과 리소스 로딩으로 나눠 Lighthouse 점수를 51에서 82로 올렸고, 금융사마다 달라지는 로직은 전략 패턴으로 분리했습니다.

합류 후에는 모바일 웹의 로딩과 흐름부터 점검해 사장님이 리뷰 관리에 쓰는 시간을 더 줄이겠습니다.
